# 白板字体许可

字体文件取自 `@excalidraw/excalidraw@0.18.0` 与 `cn-fontsource-lxgw-marker-gothic-regular@1.0.1` 发行包（已按 unicode-range 切片，未修改字形），由 `scripts/gen-board-fonts.mjs` 复制到此目录。

| 字体 | 用途 | 许可 | 来源 |
|---|---|---|---|
| 霞鹜漫黑 LXGW Marker Gothic | 白板中文（主字体） | SIL Open Font License 1.1 | https://github.com/lxgw/LxgwMarkerGothic |
| Xiaolai（小赖字体） | 白板生僻字兜底 | SIL Open Font License 1.1；不得单独出售字体文件 | https://github.com/lxgw/kose-font |
| Excalifont | 白板空格、标点等（比例字体） | SIL Open Font License 1.1 | https://plus.excalidraw.com/excalifont |
| Comic Shanns | 白板英文字母与数字 | MIT | https://github.com/jesusmgg/comic-shanns |
| 站酷快乐体 ZCOOL KuaiLe | 白板可选字体（设置里切换） | SIL Open Font License 1.1（许可原文 ZCOOLKuaiLe/OFL.txt） | https://github.com/googlefonts/zcool-kuaile ，文件取自 `@fontsource/zcool-kuaile@5.3.0`，由 `scripts/gen-kuaile-font.mjs` 生成；小程序用的常用字子集 ZCOOLKuaiLe/mp/zcool-kuaile-common.woff 由 `scripts/gen-mp-board-font.py` 生成 |

依 OFL：字体可随软件分发；修改后的字体不得使用保留名称（Xiaolai / 小赖 / Kose 等）。
